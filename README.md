## Project Overview

**Payment Alipay Component** - Provides Alipay payment integration for Unity. Supports Android, iOS, and Editor simulation mode.

### Features

- Unified payment interface via `IAlipayManager`
- Android support (via `com.alipay.sdk.app.PayTask`)
- iOS support (via native library calls)
- Editor simulation testing (simulates successful payment callback)
- Automatic thread switching to ensure callbacks run on the main thread

## Quick Start

### Installation

Choose one of the following methods:

1. Add the following to the `dependencies` section of your project's `manifest.json`:
   ```json
   {"com.gameframex.unity.payment.alipay": "https://github.com/AlianBlank/com.gameframex.unity.payment.alipay.git"}
   ```
2. Use `Git URL` in Unity's Package Manager: https://github.com/AlianBlank/com.gameframex.unity.payment.alipay.git
3. Download the repository and place it in your Unity project's `Packages` directory.

### Usage Examples

```csharp
using GameFrameX.Runtime;
using GameFrameX.Payment.Alipay.Runtime;

public class PaymentExample : MonoBehaviour
{
    private void Start()
    {
        // 1. Get the Alipay manager interface
        var alipayManager = GameFrameworkEntry.GetModule<IAlipayManager>();

        if (alipayManager != null)
        {
            // 2. Prepare order info (usually generated by the server)
            string orderInfo = "app_id=...&biz_content=...&sign=...";

            // 3. Initiate payment
            alipayManager.Pay(orderInfo, OnPayResult);
        }
    }

    private void OnPayResult(AlipayResult result)
    {
        Debug.Log($"Payment status: {result.resultStatus}");
        Debug.Log($"Payment result: {result.result}");
        Debug.Log($"Memo: {result.memo}");

        if (result.resultStatus == "9000")
        {
            Debug.Log("Payment successful");
        }
        else
        {
            Debug.LogError("Payment failed or cancelled");
        }
    }
}
```

Ensure an `AlipayComponent` exists in your scene, either auto-loaded by GameFrameX or manually attached to a GameObject.
